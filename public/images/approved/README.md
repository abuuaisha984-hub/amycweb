# AMYC website image preparation

This is the folder to use for future photographs approved for the AMYC website. The files already supplied during this upgrade remain in `public/images/`; they have not been moved or renamed. Keep the originals and place future approved files in this folder or its subfolders:

- `hero/` — homepage and page header images
- `schools/<school-slug>/` — verified school profile and gallery images
- `regions/<region-slug>/` — verified regional profile images
- `programmes/` — programme and project images
- `gallery/<album-slug>/` — event and community albums

Please send the largest original JPG, PNG or WebP available. Landscape images around 2000 × 1100 pixels work well for a hero; around 1200 × 800 pixels is suitable for editorial and school photos. Avoid adding text or logos over photographs.

For each image, include a note with its descriptive title, useful alt text, optional caption, photographer/source, permission or licence, and date verified. Do not supply names, dates, facilities or achievement claims that AMYC has not verified.
